HOW LOCALE WORKS

A release is more than its screenshots.

  1. Declare what needs review.

    Your manifest lists each required locale, screen, state, device configuration, text size and appearance. Missing captures stay visible.

  2. Bring the capture evidence.

    Use your existing desktop or CI tools. Import exact build/catalog metadata and local PNG/JPEG images. The browser computes each image’s SHA-256.

  3. Make a human decision.

    Approve, request changes or comment in the review workspace. Replacing evidence invalidates its old decision. Review the bytes and declared context yourself.

  4. Export a portable record.

    Download JSON with declared coverage, decisions, fingerprints and unresolved items. This is a human review record, not a cryptographic signature or independently verified identity.

Local-only demo

No account, upload service or synchronization. Work is held in memory and clears on reload. Export before leaving. The supplied Vale project and its screenshots are entirely synthetic.

Public demo processing is bounded. Production multi-user identity, synchronized audit storage, capture adapters and artifact retention are future self-hosted work.
